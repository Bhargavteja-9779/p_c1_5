# Introduction

Non-target screening (NTS) by liquid chromatography–high-resolution mass spectrometry (LC–HRMS) detects thousands of features per sample, but turning a feature into a structure remains the bottleneck of exposomics, environmental monitoring and metabolomics [@hupatz2025critical]. Accurate mass and MS/MS spectra typically leave several isomeric candidate structures, so orthogonal evidence is needed to raise the confidence of an identification [@schymanski2014identifying]. Retention time (RT) is the most widely available such evidence: a candidate whose expected RT is incompatible with the observed RT of the feature can be down-weighted or discarded [@hupatz2025critical; @metz2025identification].

Using RT this way requires predicting it on the laboratory's own chromatographic system, for which training data are rarely available. Two families of approaches transfer public RT knowledge to a new system with the help of a small set of calibrant compounds measured on that system. *Projection* methods map RTs measured on other systems through a monotone relation fitted on shared compounds [@stanstrup2015predret] or project retention from isocratic data measured under controlled conditions [@boswell2011study; @abatepella2015retention], and calibrant-based retention-time indices serve a similar purpose [@aalizadeh2021development; @stoffel2022alkylpyridinium]; *prediction* methods train structure-based models on large public collections [@domingo2019smrt; @kretschmer2024report] and adapt them to the target system by calibration, fine-tuning or chromatographic-condition descriptors [@bouwmeester2020generalized; @garcia2022probabilistic; @li2025prediction; @fadil2026fastret; @xiong2026unirt], or learn representations across chromatographic methods and laboratories [@stienstra2025reverse; @wang2026hybrid]. Because absolute RTs change much more between systems than elution order, retention-order models followed by a mapping to time have recently enabled transfer without target training data [@kretschmer2026order]. An evaluation on 37 reversed-phase systems of the NORMAN interlaboratory comparison showed that the accuracy of both projection and prediction depends strongly on how similar the source and target systems are, notably in mobile-phase pH and column chemistry [@malm2025projection].

For candidate filtering, however, the accuracy of the point prediction is only half of the story: a *tolerance window* must be chosen around it. In practice windows are fixed (e.g. ±0.1–0.5 min [@metz2025identification], ±0.40 min [@kretschmer2026order] or ±3 min [@mceachran2018comparison]), expressed as a fraction of the run time (±15 % [@mceachran2018comparison]), or derived from calibration residuals, for example ±2 RMSE, expected to contain about 95 % of true RTs [@malm2025projection]. Boswell et al. computed projection-specific tolerance windows from the expected error of retention projection, aiming to exclude candidates with a stated confidence; across seven laboratories, these windows had to be relaxed by 50 % to be appropriate for all of them [@boswell2015calculation]. Projection tools report prediction intervals for the projected RTs [@stanstrup2015predret]; Gaussian-process projections with meta-learned priors yield predictive distributions from as few as ten calibrants [@garcia2022probabilistic]; and recent models provide ensemble-, Bayesian- or similarity-based uncertainty estimates [@maboudi2017uncertainty; @matyushin2024uncertainty; @geer2024airi; @beck2026uncertainty; @wiczling2026bayesian]. None of these windows guarantees that the *correct* structure is retained with a stated probability on a new system. Where the fraction of correct structures that survives filtering has been measured, losses were substantial: RT thresholds discarded 21–41 % of correct identities on four external methods [@domingo2019smrt], a ±3 min window retained only 42 % or 83 % of known chemicals depending on the RT model [@mceachran2018comparison], retention-index filtering eliminated 12 of 91 true metabolites where 4–5 had been expected [@samaraweera2018evaluation], and 6–20 % of true identities were still removed after post-projection calibration with 35 calibrants [@zhang2024generic]. These evaluations covered only a few chromatographic systems, and none provided a way to control the loss. The asymmetry of filtering errors makes this important: a window that is too wide merely keeps some wrong candidates, whereas a window that is too narrow silently removes the right answer, which no downstream scoring can recover, because identification probabilities are computed only over the candidates that pass the tolerance windows [@metz2025identification].

Conformal prediction provides distribution-free prediction intervals with finite-sample coverage guarantees under an exchangeability assumption, for any underlying model [@vovk2005algorithmic; @lei2018distribution; @angelopoulos2023gentle]. The jackknife+ variant reuses all calibration points for both fitting and calibration [@barber2021jackknife], which is attractive when only a handful of calibrants exist. When the data drift away from the calibration set, validity can be lost, and updating the calibration set with data resembling the new data generally improves it [@morger2022studying] — the role that calibrants measured on the target system can play for RT. Conformal methods have recently entered analytical chemistry for spectroscopic calibration [@wiens2026calibrated], including under deployment shift [@bhargav2026group], for candidate retrieval from tandem mass spectra [@rakhshaninejad2026reliable], for the prioritisation of NTS features [@kreutzer2026molecular] and, most closely related to this work, for candidate prioritisation with predicted collision cross sections (CCS), where a normalised conformal predictive system guaranteed the fraction of true structures retained [@ferrandoplo2026candidate]. Earlier CCS prediction-interval filters had been applied without such guarantees [@wen2023structural]. Retention time poses a problem that CCS does not: because RTs are system-specific, the window must be calibrated on each laboratory's chromatographic system, typically from 10–50 calibrants [@aalizadeh2021development; @garcia2022probabilistic; @zhang2024generic; @malm2024norman; @kretschmer2026order], and the same calibrants must also be used to map the model to that system. To our knowledge, conformal windows for this few-calibrant transfer setting have not been developed or evaluated.

Here we (i) measure, on {{n_target_systems}} reversed-phase systems from RepoRT with leave-source-out validation, how often current RT-window constructions — parametric intervals, fixed and proportional tolerances, and residual-based rules — discard the correct structure on a new system calibrated with 10–40 compounds; (ii) construct calibrant-based jackknife+ windows that retain the correct structure at a user-chosen rate under an explicit exchangeability assumption, optionally normalised by a difficulty model meta-learned on other chromatographic systems, and make explicit the minimum number of calibrants they require; (iii) quantify the resulting trade-off between retaining correct structures and eliminating isomeric false candidates; (iv) test robustness to calibrant errors, the base model and the separation mode (HILIC) and validate the approach externally on {{norman.n_systems}} interlaboratory NTS methods; and (v) show that calibrant mixes unlike the analytes break the guarantee, and propose a selection-aware calibration that corrects a known calibrant-selection rule while delimiting what it cannot correct. All code and results are provided as Supplementary Material and will be deposited in a public repository upon acceptance.
