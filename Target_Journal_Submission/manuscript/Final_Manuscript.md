# Highlights {.unnumbered}
- Parametric and fixed RT windows lose correct structures on new LC systems
- Calibrant-based conformal windows keep a user-chosen retention rate
- At least 1/α − 1 calibrants are needed for a finite window
- Calibrants must resemble the analytes; known selection rules can be corrected
- Tested on 228 RepoRT systems and 37 interlaboratory NTS methods

# Abstract {.unnumbered}
**Background.** Retention-time (RT) filters discard candidate structures in liquid chromatography–high-resolution mass spectrometry (LC–HRMS) non-target screening, but their tolerance windows are set heuristically, and the probability that the correct structure survives on a laboratory's own chromatographic system is unknown. We aimed to construct RT windows that retain the correct structure at a user-chosen rate using only the calibrants that a laboratory measures.

**Results.** A retention-order model trained on public RepoRT data was mapped to each target system through its calibrants, and jackknife+ conformal windows were computed from the calibrants, optionally normalised by a difficulty model meta-learned on other systems. On 228 reversed-phase systems in leave-source-out validation (20 calibrants, nominal 90 %), Gaussian-process, smoothing-spline and ±z·RMSE windows retained the correct structure in 82.2 %, 85.1 % and 88.5 % of cases and fixed ±1 min windows in 70.5 %, whereas conformal windows retained 90.9 %–91.1 %; this held for HILIC and for 37 interlaboratory NTS methods. Finite windows require at least $1/\alpha-1$ calibrants. Normalisation improved efficiency for longer-than-median runs (median change in interval score versus jackknife+ -17 %) but not for short runs, HILIC or the external systems. Calibrant mixes unlike the analytes broke validity (86.9 % for an interlaboratory calibrant mix); replaying a known selection rule on public data restored 90.2 % for common-compound calibrants.

**Significance.** Calibrant-based conformal RT windows turn the probability of keeping the correct structure from an unknown into a design choice, provided that the calibrants represent the analytes; conventional windows silently discard many correct structures on new systems. An open implementation needs only calibrant RTs and candidate SMILES.

**Keywords:** non-target screening; retention-time prediction; conformal prediction; uncertainty quantification; compound identification; LC–HRMS


# Introduction

Non-target screening (NTS) by liquid chromatography–high-resolution mass spectrometry (LC–HRMS) detects thousands of features per sample, but turning a feature into a structure remains the bottleneck of exposomics, environmental monitoring and metabolomics [@schymanski2014identifying; @hupatz2025critical]. Accurate mass and MS/MS spectra typically leave several isomeric candidate structures, so orthogonal evidence is needed. Retention time (RT) is the most widely available such evidence: a candidate whose expected RT is incompatible with the observed RT of the feature can be down-weighted or discarded [@hupatz2025critical; @metz2025identification].

Using RT this way requires predicting it on the laboratory's own chromatographic system, for which training data are rarely available. Two families of approaches transfer public RT knowledge to a new system with the help of a small set of calibrant compounds measured on that system. *Projection* methods map RTs measured on other systems through a monotone relation fitted on shared compounds [@stanstrup2015predret], and calibrant-based retention-time indices serve the same purpose [@aalizadeh2021development]; *prediction* methods train structure-based models on large public collections [@domingo2019smrt; @kretschmer2024report] and adapt them to the target system by calibration, fine-tuning or chromatographic-condition descriptors [@garcia2022probabilistic; @fadil2026fastret; @xiong2026unirt]. Because absolute RTs change much more between systems than elution order, retention-order models followed by a mapping to time have recently enabled transfer without target training data [@kretschmer2026order]. An inter-laboratory evaluation on 37 systems showed that the accuracy of both projection and prediction depends strongly on how similar the source and target systems are, notably in mobile-phase pH and column chemistry [@malm2025projection].

For candidate filtering, however, the accuracy of the point prediction is only half of the story: a *tolerance window* must be chosen around it. In practice windows are fixed (e.g. ±0.1–0.5 min [@metz2025identification], ±0.40 min [@kretschmer2026order] or 3 min [@mceachran2018comparison]), expressed as a fraction of the run time (±15 % [@mceachran2018comparison]), or derived from calibration residuals, for example ±2 RMSE, expected to contain about 95 % of true RTs [@malm2025projection]. Projection tools report prediction intervals for the projected RTs [@stanstrup2015predret]; Gaussian-process projections with meta-learned priors yield predictive distributions from as few as ten calibrants [@garcia2022probabilistic]; and recent models provide ensemble-, Bayesian- or similarity-based uncertainty estimates [@matyushin2024uncertainty; @beck2026uncertainty; @wiczling2026bayesian]. None of these windows guarantees that the *correct* structure is retained with a stated probability on a new system. Where the fraction of correct structures that survives filtering has been measured, losses were substantial: RT thresholds discarded 21–41 % of correct identities on four external methods [@domingo2019smrt], a 3-min window retained only 42 % or 83 % of known chemicals depending on the RT model [@mceachran2018comparison], and 6–20 % of true identities were still removed after post-projection calibration with 35 calibrants [@zhang2024generic]. These evaluations covered only a few chromatographic systems, and none provided a way to control the loss. The asymmetry of filtering errors makes this important: a window that is too wide merely keeps some wrong candidates, whereas a window that is too narrow silently removes the right answer, and the loss propagates to every downstream identification-confidence assignment [@metz2025identification].

Conformal prediction provides distribution-free prediction intervals with finite-sample coverage guarantees under an exchangeability assumption, for any underlying model [@vovk2005algorithmic; @lei2018distribution; @angelopoulos2023gentle]. The jackknife+ variant reuses all calibration points for both fitting and calibration [@barber2021jackknife], which is attractive when only a handful of calibrants exist. Conformal methods have recently entered analytical chemistry for spectroscopic calibration under deployment shift [@bhargav2026group; @wiens2026calibrated], for candidate retrieval from tandem mass spectra [@rakhshaninejad2026reliable] and, most closely related to this work, for candidate prioritisation with predicted collision cross sections (CCS), where a normalised conformal predictive system guaranteed the fraction of true structures retained [@ferrandoplo2026candidate]. Earlier CCS prediction-interval filters had been applied without such guarantees [@wen2023structural]. Retention time poses a problem that CCS does not: because RTs are system-specific, the window must be calibrated on each laboratory's chromatographic system, typically from 10–50 calibrants, and the same calibrants must also be used to map the model to that system. To our knowledge, conformal windows for this few-calibrant transfer setting have not been developed or evaluated.

Here we (i) measure, on 228 reversed-phase systems from RepoRT with leave-source-out validation, how often current RT-window constructions — parametric intervals, fixed and proportional tolerances, and residual-based rules — discard the correct structure on a new system calibrated with 10–40 compounds; (ii) construct calibrant-based jackknife+ windows that retain the correct structure at a user-chosen rate under an explicit exchangeability assumption, optionally normalised by a difficulty model meta-learned on other chromatographic systems, and derive the minimum number of calibrants they require; (iii) quantify the resulting trade-off between retaining correct structures and eliminating isomeric false candidates; (iv) test robustness to calibrant errors, the base model and the separation mode (HILIC) and validate the approach externally on 37 interlaboratory NTS methods; and (v) show that calibrant mixes unlike the analytes break the guarantee, and propose a selection-aware calibration that corrects a known calibrant-selection rule while delimiting what it cannot correct. All code and results are openly available.


# Theory and calculation

## Problem formulation

Let $T$ denote the chromatographic system used in a non-target screening (NTS) study and $t(x)$ the retention time (RT) of compound $x$ on $T$. A laboratory measures a set of $n$ calibrants $\mathcal{D}_n=\{(x_i,t_i)\}_{i=1}^{n}$ on $T$ and has access to public RT data acquired on other systems. For a candidate structure $x$ proposed for an LC-HRMS feature with observed retention time $t_{\mathrm{obs}}$, the candidate is retained if $t_{\mathrm{obs}}\in C_\alpha(x)$, where $C_\alpha(x)$ is an RT window. The quantity that matters for annotation is the probability that the *correct* structure survives the filter, $\mathbb{P}\{t(x)\in C_\alpha(x)\}$ (coverage); its complement is the false-rejection rate of the filter. The second quantity is the fraction of incorrect candidates removed, which decreases as windows widen. We therefore seek windows whose coverage is controlled at a user-chosen level $1-\alpha$ for compounds of the target system, using only the $n$ calibrants and data from other systems, and that are as narrow as this constraint permits.

## Base retention-order score

Absolute RTs change strongly between systems, whereas elution order is far better conserved [@kretschmer2026order]. We therefore learn a system-independent score $s(x)$ whose ordering agrees with the elution order observed within each training system. Training data are all RP systems from sources other than that of $T$ (plus a 15,000-compound subsample of the METLIN SMRT system [@domingo2019smrt]). A gradient-boosted ranking model (XGBoost, pairwise objective with query groups = chromatographic systems [@chen2016xgboost]) is fitted on 217 RDKit two-dimensional descriptors and a 1024-bit Morgan count fingerprint (radius 2) [@rdkit]. Because only the order of $s$ is used, no per-system normalisation of RTs is required.

## Monotone calibrant mapping

On the target system the score is mapped to time by a monotone function $g$ fitted on the calibrants: isotonic regression of $t_i$ on $s_i$, followed by piecewise-cubic Hermite (PCHIP) interpolation through the isotonic fit, and linear extrapolation beyond the calibrant score range with the Theil–Sen slope of the calibrants. Monotonicity encodes the assumption that the base score preserves elution order on $T$; deviations from this assumption (selectivity changes) appear as residuals and are absorbed by the window. Leave-one-out (LOO) maps $g_{-i}$ are obtained by refitting without calibrant $i$.

## Conformal retention-time windows

*Jackknife+.* With LOO residuals $R_i=|t_i-g_{-i}(s_i)|$, define for a compound $x$ the $n$ values $v^{\mathrm{hi}}_i(x)=g_{-i}(s(x))+R_i$ and $v^{\mathrm{lo}}_i(x)=g_{-i}(s(x))-R_i$. The jackknife+ window [@barber2021jackknife] is
$$C_\alpha(x)=\left[\,v^{\mathrm{lo}}_{(k_{\mathrm{l}})}(x),\ v^{\mathrm{hi}}_{(k_{\mathrm{u}})}(x)\,\right],$$
where $v_{(k)}$ denotes the $k$-th smallest of the $n$ values, $k_{\mathrm{u}}$ is $(1-\alpha)(n+1)$ rounded up and $k_{\mathrm{l}}$ is $\alpha(n+1)$ rounded down. If calibrants and the compound of interest are exchangeable draws from the compounds analysed on $T$, then $P\{t(x)\in C_\alpha(x)\}\ge 1-2\alpha$ for any mapping algorithm, and coverage is close to $1-\alpha$ in practice [@barber2021jackknife]. The window is finite only if $k_{\mathrm{u}}\le n$, i.e.
$$n\ \ge\ \frac{1}{\alpha}-1,$$
so that at least 9 calibrants are needed for $\alpha=0.10$, 19 for $\alpha=0.05$ and 4 for $\alpha=0.20$.

*Normalised jackknife+ with a meta-learned difficulty model (proposed).* RT errors after transfer are strongly heteroscedastic: they depend on the compound (e.g. ionisable groups whose charge state differs between mobile phases, compounds dissimilar to the training data) and on where the compound falls relative to the calibrants (interpolation versus extrapolation). Let $\sigma(x;\mathcal{D})>0$ be a difficulty (scale) function. With $\sigma_{-i}$ denoting the difficulty function computed with calibrant $i$ left out of $\mathcal{D}_n$ and normalised scores $R_i=|t_i-g_{-i}(s_i)|/\sigma_{-i}(x_i)$, the window is defined as above with
$$v^{\mathrm{hi}}_i(x)=g_{-i}(s(x))+\sigma_{-i}(x)R_i,\qquad v^{\mathrm{lo}}_i(x)=g_{-i}(s(x))-\sigma_{-i}(x)R_i.$$
Because $\sigma_{-i}$ is computed from the leave-one-out calibrant set by the same symmetric procedure that produces $g_{-i}$, the argument of Barber et al. [@barber2021jackknife, Thm. 1] applies verbatim to the scaled score, and the $1-2\alpha$ guarantee is retained (proof in Supplementary Section S2). The function $\sigma$ itself is learned only from other chromatographic systems and is therefore fixed with respect to the target data.

## Meta-learned difficulty model

The difficulty model is $\sigma(x;\mathcal{D})=\exp\{h(\phi(x,\mathcal{D},z_T))\}+10^{-3}$ min, where $h$ is a gradient-boosted regression tree ensemble (LightGBM [@lightgbm]) and $\phi$ concatenates five feature groups: (i) *physicochemical* descriptors (logP, TPSA, molecular weight, H-bond donors/acceptors, rotatable bonds, fraction sp³, ring counts, molar refractivity, Labute ASA, element counts); (ii) *ionisation* features (SMARTS counts of carboxylic, sulfonic and phosphonic acids, phenols, primary/secondary/tertiary aliphatic amines, quaternary nitrogen, amidines/guanidines, pyridine- and imidazole-type nitrogens, formal charge); (iii) *novelty* features (maximum Tanimoto similarity of $x$ to the base-model training compounds and an exact-match flag); (iv) *calibrant-geometry* features computed from $\mathcal{D}$ (position of $s(x)$ relative to the calibrant score range, extrapolation distance, gap to the nearest calibrant score, calibrant RT span, number of calibrants); and (v) *system* descriptors $z_T$ from routinely reported metadata (mobile-phase pH class, organic modifier, USP column class, column length, particle size, temperature, flow rate, gradient duration, dead time). $h$ is trained to predict $\log(|r|+0.01\ \mathrm{min})$ for transfer residuals $r$ generated by *simulating the calibrant protocol* on training systems: for each training system, random calibrant sets of size 10, 20 and 40 are drawn (three draws each), the monotone map is fitted, and residuals of all remaining compounds are recorded. To make these residuals representative of transfer to an unseen system, base scores for each training source group are produced by a base model trained without that group (inner cross-fitting, Fig. 1).

## Selection-aware system-level calibration

The guarantee above requires calibrants that are exchangeable with the analytes, which a fixed calibrant mix need not be. If the rule $\rho$ by which a laboratory selects its calibrants (for example, "the most commonly measured compounds" or "the chemicals of a given standard mix") is known, it can be replayed on $S$ training systems, which are then the exchangeable units. With $\mathrm{cov}_s(c)$ the coverage on training system $s$ of windows in which every scaled score $\sigma_{-i}(x)R_i$ is multiplied by $c$, the selection-aware factor is
$$c_\rho=\min\left\{c:\ \frac{1}{S}\sum_{s=1}^{S}\mathrm{cov}_s(c)\ \ge\ 1-\alpha\right\},$$
computed with base and difficulty models that did not see system $s$; the target system's windows are then built with $c_\rho$. The resulting control is of average coverage over systems that share the selection rule and the analyte population, not a per-system finite-sample guarantee.

## Comparator windows

All comparators use the same base score, the same calibrants and (where applicable) the same monotone map: (B1) Gaussian window $g(s(x))\pm z_{1-\alpha/2}\,\mathrm{RMSE}_{\mathrm{LOO}}$, representing the common practice of setting the tolerance from calibration residuals; (B2) penalised cubic B-spline (P-spline, GAM-like) mapping with the classical prediction interval $\hat t\pm t_{1-\alpha/2,\,n-\mathrm{edf}}\,\hat\sigma\sqrt{1+h(x)}$ and smoothing parameter chosen by generalised cross-validation, analogous to the projection intervals of PredRet [@stanstrup2015predret]; (B3) Gaussian-process projection (RBF + linear + white-noise kernel, marginal-likelihood hyper-parameters) with Gaussian predictive intervals, analogous to GP-based projection [@garcia2022probabilistic]; (B4) split conformal prediction [@papadopoulos2002inductive; @lei2018distribution] with half of the calibrants used for fitting and half for calibration; (B5) unnormalised jackknife+; and (B6) jackknife+ normalised by the spread of five bootstrap-replicate base models (a standard heuristic uncertainty signal [@matyushin2024uncertainty]), computed leave-one-out consistently.

## Data

All RT data were taken from RepoRT v1.0 [@kretschmer2024report], a curated repository of small-molecule RTs with standardised structures and chromatographic metadata (Zenodo record 10.5281/zenodo.16267768, CC BY-SA 4.0; archive SHA-256 4eeeb46a…6091). Compounds were identified by the connectivity block of the standard InChIKey; stereoisomer entries within a system were averaged when their RTs differed by ≤0.2 min and removed otherwise. Mobile-phase pH class and organic modifier were derived from the reported additives and solvents. Target systems were all reversed-phase (RP) systems with at least 60 compounds after cleaning, excluding METLIN SMRT, which served only as an auxiliary training library: 228 systems with 65,590 retention times (median 130 compounds per system; Table 1, Fig. S1). HILIC systems with ≥60 compounds were analysed separately as an out-of-mechanism test (37 systems).

## Evaluation protocol and leakage control

Systems were partitioned by data source into five leave-source-out folds (BGC: 66 systems; Folberth: 63 systems; Other sources: 22 systems; PredRet: 41 systems; Souihi+Stoffel: 36 systems). For each fold, the base model, the bootstrap ensemble (B6) and the difficulty model were trained exclusively on systems from the other four folds (and SMRT; numbers of training systems per fold in Table S1); the only information taken from a target system was its calibrants. Within each target system, calibrant sets of size $n\in\{10,15,20,30,40\}$ were drawn uniformly at random (20 draws per $n$, fixed seeds), and all remaining compounds of the system formed the test set; windows were computed for $\alpha\in\{0.05,0.10,0.20\}$. The primary setting ($n=20$, $\alpha=0.10$), all comparators, metrics and statistical tests were specified in a plan written before any target-system result was inspected (code/EXPERIMENT_PLAN.md). Because many compounds of a target system also occur in public data from other laboratories (73 % of test compounds at $n=20$ were present in the base model's training data), test compounds were additionally stratified into those seen and not seen by the base model, and by their maximum Tanimoto similarity to its training set.

Pre-specified robustness experiments used $n=20$ and 10 draws per system with (i) calibrants spread over the RT range (one random compound per RT quantile stratum), (ii) the 20 compounds of each system most frequently measured across RepoRT, (iii) Gaussian noise with a standard deviation of 2 % of the RT span added to the calibrant RTs and (iv) one calibrant shifted by 10 % of the span. Generalisation was assessed with a second base model (a LightGBM regressor trained on SMRT only) and on HILIC systems (base and difficulty models trained on HILIC systems from other sources), and sensitivity to the difficulty-model hyper-parameters with 15 or 63 leaves and 200 or 800 trees. Analyses added after the plan was written but before the corresponding results were computed are labelled post hoc: fixed-tolerance windows on the same calibrant draws, very small calibrant sets ($n=5$ and 8), the external validation on NORMAN data and the selection-aware calibration (plan addenda B–D).

## Metrics

For each system and draw we computed empirical coverage (fraction of test compounds whose RT lies in their window), mean and median window width (min), and the Winkler interval score [@winkler1972decision; @gneiting2007strictly]
$$\mathrm{IS}_\alpha(l,u;t)=(u-l)+\frac{2}{\alpha}(l-t)\,\mathbb{1}\{t<l\}+\frac{2}{\alpha}(t-u)\,\mathbb{1}\{t>u\},$$
a proper score that rewards narrow windows but penalises misses, so that an under-covering method cannot appear efficient merely by being narrow. Candidate-filtering performance was evaluated with *isomeric decoys*: for each test compound, up to 30 RepoRT compounds with the same molecular formula but a different connectivity block were treated as incorrect candidates; a decoy was eliminated when the observed RT of the true compound fell outside the decoy's window (draws 0–4 at $n=20$).

## Statistical analysis

The unit of analysis is the target system; metrics were averaged over draws within each system. Mean coverage is reported with 95 % bootstrap confidence intervals (10,000 resamples of systems) and, as a sensitivity analysis, with a cluster bootstrap over source folds. The proposed method was compared with each comparator by two-sided Wilcoxon signed-rank tests on per-system interval scores, widths and absolute coverage gaps, with Holm correction within each metric family [@holm1979simple] and the matched-pairs rank-biserial correlation as effect size [@kerby2014simple]. Robustness experiments used 10 draws per system.

## Implementation

All computations ran on a 4-core CPU without GPU. Code (Python 3.13; RDKit, XGBoost, LightGBM, scikit-learn, SciPy), configuration files, unit tests (including a simulation check of the jackknife+ coverage guarantee), the pre-registered plan and all raw outputs are provided (see Data availability); every number, table and figure in this article is regenerated by `python run_all.py --mode full`.


# Results and discussion

## Coverage of current retention-time windows on new systems

With $n=20$ randomly drawn calibrants and a nominal 90 % window, the parametric windows retained the correct structure less often than intended (Table 2, Fig. 2a). Mean coverage over the 228 target systems was 0.822 for Gaussian-process projection intervals, 0.851 for P-spline prediction intervals and 0.885 for the Gaussian ±z·RMSE window, and coverage fell below 0.85 in 82 %, 49 % and 4 % of the systems, respectively. The deficit grew as calibrants became scarcer: at $n=10$, mean coverage was 0.714 (GP), 0.760 (P-spline) and 0.862 (Gaussian) (Fig. 3a). In contrast, every conformal construction reached the nominal level on average: 0.909 for jackknife+, 0.909 for split conformal prediction and 0.911 (95 % CI 0.908–0.913) for the proposed windows, and no target system had a mean coverage below 0.85 with the proposed windows. The conformal windows tracked the nominal level at every $\alpha$ (at $n=20$: 0.958 for $\alpha=0.05$ and 0.812 for $\alpha=0.20$), whereas the parametric windows were miscalibrated in an $\alpha$-dependent direction (Fig. S2, Table S2): at $\alpha=0.05$ all three under-covered (Gaussian 0.916, P-spline 0.892, GP 0.864), while at $\alpha=0.20$ the Gaussian window over-covered (0.829) and the GP and P-spline intervals still under-covered (0.750 and 0.778). Such level-dependent errors are the signature of heavy-tailed transfer residuals, for which a normal quantile is too wide near the centre and too narrow in the tails. Coverage of the conformal windows was also at the nominal level in each of the five source folds (Table S7), and a cluster bootstrap over source folds gave practically identical confidence intervals (Table S3). These results confirm H1 and H2: windows derived from parametric error models transfer their optimism to new systems, whereas calibrant-based conformal windows keep the promised error rate without any target-system training data.

Fixed tolerances, which are still widely used, fared worse (Table 2, Table S6; evaluated on the same calibrant draws, post hoc). With 20 calibrants, windows of ±0.25, ±0.5, ±1 and ±2 min retained the correct structure in 39 %, 54 %, 71 % and 85 % of cases on average, and relative windows of ±5 % and ±10 % of the predicted RT in 34 % and 53 %. A fixed window cannot adapt to systems whose RT errors differ by an order of magnitude: even ±2 min kept fewer than 85 % of the correct structures in 43 % of the systems. Residual-based windows of ±2·RMSE and ±3·RMSE, often read as approximately 95 % and 99.7 % intervals, delivered 91.9 % and 96.4 % at $n=20$ and 89.8 % for ±2·RMSE at $n=10$. In terms of the interval score, the proposed windows were better than every fixed or residual-based tolerance at every calibrant number (Table S6).

## Efficiency: interval score and width

Among the methods with valid coverage, the proposed windows were the narrowest (median width 4.68 min, i.e. 35 % of the system's RT span, versus 5.06 min for jackknife+, 7.04 min for split conformal prediction and 9.97 min for jackknife+ normalised by ensemble spread), and they achieved the lowest mean interval score of all methods (9.07 min; Table 2, Fig. 2c). Paired by system, the interval score of the proposed windows was lower than that of jackknife+ by a median of -0.43 min (95 % CI -0.93 to -0.20; rank-biserial correlation -0.47; Holm-adjusted $p$ < 0.001), and lower than those of the Gaussian, P-spline and GP windows in 62 %, 62 % and 60 % of the systems, respectively (Table 3; all calibrant numbers and α levels in Table S4). The parametric windows were narrower still (median 3.40–4.25 min), but this narrowness is precisely what made them under-cover, and the interval score penalises the resulting misses. Normalising jackknife+ by the spread of bootstrap-replicate base models — a common heuristic uncertainty signal — over-covered and more than doubled the window width, showing that the choice of the scale function matters.

## Heterogeneity of the gain across systems

The improvement over plain jackknife+ was not uniform (Table 3). The interval score decreased by a median of -18.2 % in the Folberth systems (better in 95 % of them) and by -10.1 % in the Souihi and Stoffel systems, whereas the median change was 2.7 % in the BGC systems ($p$ = 0.09), 0.4 % in PredRet and 0.5 % in the remaining sources. Against the Gaussian window, the proposed windows were even slightly worse in the BGC fold (5.7 %; $p$ = 0.002), although the Gaussian window under-covered there as elsewhere. The relative gain over jackknife+ increased with the length of the chromatographic run (Spearman $\rho$ = -0.53, $p$ < 0.001): systems whose RT span exceeded the median of 16.8 min gained -16.8 %, whereas shorter systems changed by 2.3 %. A plausible explanation, consistent with the conditional-coverage results below, is that long gradients produce markedly heteroscedastic transfer errors (late eluters and compounds outside the calibrant range are mapped less precisely), which the difficulty model captures, whereas in short gradients the errors are nearly homoscedastic and estimating a scale function adds variance without reducing bias. Practically, plain jackknife+ is an adequate and simpler choice for short gradients, and the normalised version pays off as runs get longer.

## Number of calibrants

Conformal windows are finite only if $n\ge 1/\alpha-1$. Accordingly, all jackknife+-type windows were infinite at $\alpha=0.05$ for $n=10$ and $15$, and split conformal prediction, which calibrates on only half of the calibrants, was also infinite at $\alpha=0.10$ for $n\le 15$ (Fig. 3, Table S2). Above these limits, the mean coverage of the proposed windows at $\alpha=0.10$ was 0.903–0.945; the small excess at $n=15$ (0.945) is the expected conservativeness of the discrete quantile index, whose effective level is $k_{\mathrm{u}}/(n+1)=15/16$. The median width of the proposed windows decreased from 7.02 min at $n=10$ to 4.68 min at $n=20$ and 3.66 min at $n=40$, and it was smaller than that of jackknife+ at every $n$ (7.95, 5.06 and 4.16 min). For 95 % windows, the proposed method gave a median width of 7.10 min at $n=20$ and 5.37 min at $n=40$ with coverage 0.958 and 0.953. With fewer calibrants than the bound (exploratory runs with $n=5$ and $8$; Table S5), conformal windows at $\alpha=0.10$ were infinite, i.e. the data honestly did not support the requested error rate, whereas the parametric intervals remained finite but became severely over-confident: GP and P-spline intervals covered 57 % and 57 % of the true RTs at $n=5$, and the Gaussian window 83 %. At $\alpha=0.20$, for which eight calibrants suffice, the proposed windows were valid (0.907 at $n=8$) while GP intervals covered 60 %. Because about 20 calibrants are the minimum for a finite 95 % window and widths kept shrinking up to the largest calibrant set tested (40), laboratories that rely on RT filtering benefit from calibrant mixes of at least 20, and preferably 30–40, compounds.

## Conditional coverage

The guarantee concerns the average over the compounds of a system; it does not ensure coverage within every compound group (Fig. 4, Tables S9–S11). The groups that matter most for NTS were also the most difficult. For compounds whose base score lay outside the range spanned by the calibrants, coverage fell to 0.755 with jackknife+ and 0.716 with the Gaussian window, but was 0.879 with the proposed windows; for the late-eluting third of compounds the values were 0.805, 0.772 and 0.863, and for compounds absent from the base model's training data 0.798, 0.765 and 0.835. Inside the calibrant range the proposed windows were slightly less conservative than jackknife+ (0.914 vs 0.926): the difficulty model moves width from easy to difficult compounds, which is the intended behaviour. Coverage nevertheless remained below nominal for compounds that were neither seen by the base model nor similar to its training data (Tanimoto 0.4–0.7: 0.781; < 0.4: 0.848), so windows for structurally novel candidates should be interpreted with caution or widened, for example by calibrating them on a Mondrian partition by novelty when enough calibrants are available.

## Candidate filtering with isomeric decoys

On average, 157 test compounds per system had at least one isomeric decoy, with 634 decoys in total (Table S13). The proposed 90 % windows retained the correct candidate for 91.4 % of the features and eliminated 24.3 % of the decoys, indistinguishable from jackknife+ (91.5 % and 24.6 %; $p$ = 0.50; Table S14). At the same nominal level, the parametric windows eliminated more decoys (Gaussian 28.2 %, P-spline 35.1 %, GP 38.3 %) only because they also discarded more correct structures (retention 89.1 %, 85.2 % and 82.2 %). When compared at matched retention, all constructions lay on nearly the same trade-off curve (Fig. 5): at 85 % retention, decoy elimination ranged from 32.9 % (proposed) to 35.3 % (P-spline), and at 90 % retention from 26.3 % (proposed) to 26.7 % (Gaussian), a level the GP and P-spline intervals did not reach at any tested $\alpha$ (Table S15). Fixed ±2 min windows retained a similar share of correct structures (85.1 %) but eliminated fewer decoys (30.4 %) than the model-based windows at 85 % retention (Table S16). Conformal windows therefore do not filter more efficiently; their contribution is that the operating point is known before the analysis: a laboratory that chooses $\alpha=0.10$ obtains about 90 % retention of correct structures on its own system, whereas the retention delivered by a nominal 90 % parametric interval is unknown in advance and was, on average, 82.2 % for GP projection. RT filtering alone removed only about a quarter to a third of isomeric decoys at these retention levels, which reiterates that RT is a supporting rather than a decisive line of evidence and is best combined with MS/MS and CCS evidence [@metz2025identification; @ferrandoplo2026candidate].

## Ablation of the difficulty model

Every feature group contributed (Fig. 6, Table S17). Removing the physicochemical, calibrant-geometry, system, novelty or ionisation features increased the median interval score by 0.61, 0.58, 0.32, 0.18 and 0.08 min, respectively (all Holm-adjusted $p$ < 0.001), while marginal coverage was unchanged, as guaranteed. Two design choices were essential. Computing the scores from in-sample residuals of the full calibrant fit instead of leave-one-out refits — a tempting shortcut — reduced mean coverage to 0.708, an empirical confirmation that the leave-one-out construction is what makes the guarantee hold. Replacing the monotone map by a linear one increased the interval score by 1.48 min, reflecting the curvature of RT mappings between gradients. The results were insensitive to the difficulty-model hyper-parameters: with 15 or 63 leaves and 200 or 800 trees, the mean interval score ranged from 9.07 to 9.23 min at unchanged coverage, always below that of jackknife+ (Table S18).

## Robustness to calibrant selection and calibrant errors

Calibrant selection is where the exchangeability assumption is most likely to fail in practice (Table 4, Fig. 7, Table S19). When the calibrants were chosen to span the RT range, as is usual when a calibrant mix is designed, the conformal windows became slightly conservative (0.928 for the proposed windows and 0.929 for jackknife+): spreading the calibrants left fewer test compounds outside their range (6.8 % versus 9.5 % for random calibrants; Table S20), whereas the leave-one-out residuals of the extreme calibrants are themselves extrapolations. Noisy calibrant RTs (Gaussian noise with a standard deviation of 2 % of the RT span) and a single outlying calibrant (shifted by 10 % of the span) also made the conformal windows conservative (0.928 and 0.926), because calibrant errors inflate the calibration residuals; GP intervals remained invalid in all three scenarios (0.842–0.858).

The decisive failure occurred when the calibrants were the 20 compounds of each system that are most frequently measured across RepoRT, a proxy for mixes of well-known reference standards. All windows then under-covered markedly: 0.815 for the proposed windows, 0.746 for jackknife+, 0.724 for the Gaussian window and 0.668 for GP intervals. Two mechanisms were at work (Table S20). Commonly measured compounds cluster in part of the elution range, so that 26.7 % of the test compounds lay outside the calibrant score range (versus 9.5 % with random calibrants); and they are easier to predict than typical analytes, so that coverage fell even inside the calibrant range (0.834). The difficulty model mitigated the first mechanism — coverage outside the calibrant range was 0.746 with the proposed windows versus 0.551 with jackknife+ — but could not remove the bias. Calibrant mixes therefore need to span the RT range and to resemble the analytes; when a fixed selection rule is used, the correction described in the next sections is required.

## Generalisation to another base model and to HILIC

Replacing the multi-system retention-order model by a gradient-boosted regressor trained on the METLIN SMRT system only — the common "pre-train on SMRT, then project" approach — left the validity conclusions unchanged (at $n=20$: proposed 0.912, jackknife+ 0.908, Gaussian 0.879, GP 0.820; Table 4, Table S21) and enlarged the advantage of the proposed windows (mean interval score 11.12 versus 12.57 min for jackknife+). The windows were wider than with the retention-order model (median 6.56 versus 4.68 min), consistent with the better transferability of retention order [@kretschmer2026order]. On 37 HILIC systems, with base and difficulty models trained on HILIC data from other sources only, the conformal windows again had nominal coverage (0.903 proposed, 0.903 jackknife+) and the GP intervals again under-covered (0.819). In HILIC, however, the difficulty model increased the interval score (16.70 versus 14.33 min for jackknife+): with 33–69 heterogeneous training systems per fold, compared with 198–247 in reversed phase, the meta-learned scale function is too noisy to be useful. Together with the short-gradient results, this delimits the method: the validity of the conformal construction does not depend on the base model or the separation mode, whereas the efficiency gain of the learned normalisation requires a large and representative collection of training systems; where such a collection is lacking, plain jackknife+ should be used.

## External validation on interlaboratory NTS data

The NORMAN interlaboratory comparison provides retention times of a common set of calibration chemicals and spiked suspects measured with 37 routine NTS methods in different laboratories [@malm2025projection; @malm2024norman] and thus a test of the whole workflow on data that played no role in model development (models trained on all of RepoRT; Addendum C). When calibrants were drawn at random from all compounds, the result of the main study was reproduced (Table 4; Table S22): with 20 calibrants, the conformal windows covered 0.912 (proposed) and 0.909 (jackknife+) of the true RTs, against 0.881, 0.881 and 0.839 for the Gaussian, P-spline and GP windows. On these external systems, however, the difficulty model brought no efficiency gain (mean interval score 11.14 versus 10.70 min for jackknife+). A contributing factor may be that temperature, flow rate and dead time, which were always available for the RepoRT training systems, were not reported for the NORMAN methods and entered the difficulty model as missing values.

The realistic use case — calibrating on the laboratory's calibration chemicals and screening the suspects — revealed the limits of the exchangeability assumption. With the full set of detected calibration chemicals (37 systems, 12–36 calibrants each), mean coverage of the suspects' RTs was 0.851 (95 % CI 0.825–0.873) for the proposed windows and 0.869 for jackknife+, i.e. below the nominal 0.90 but still above the GP intervals (0.777); split conformal windows, which are wider, reached 0.916. Random subsets of 20 calibration chemicals gave the same picture (0.849 and 0.874). The calibration chemicals and the suspects are different compound populations, and no calibrant-only procedure can detect how much harder the latter are to predict.

## Selection-aware system-level calibration

When the rule by which calibrants are chosen is known, it can be replayed on other chromatographic systems, which are then the exchangeable units (Addendum D). For every leave-source-out fold, the factor $c$ by which the scaled scores $\sigma_{-i}(x)R_i$ must be multiplied so that the *average* coverage over 191–241 training systems reaches $1-\alpha$ was 1.50–1.70 for the commonly-measured-calibrant rule (jackknife+: 1.98–2.92), 0.84–0.86 for RT-spanning calibrants and 0.94–0.96 for random calibrants (Table S25). Applied to the target systems (Table 4; Table S24), this selection-aware calibration restored the coverage under the commonly-measured-calibrant rule from 0.815 to 0.902 for the proposed windows (jackknife+: from 0.746 to 0.889), at the price of wider windows (median 5.17 versus 3.22 min); for RT-spanning calibrants it removed the conservativeness and narrowed the windows from 4.35 to 3.72 min at a coverage of 0.902. Because the factor equalises the average over systems, individual systems still varied (21 % of the systems remained below 0.85 under the common-calibrant rule). The correction failed where the analyte population, rather than the calibrant selection, differed: on the 36 RepoRT systems containing at least ten NORMAN calibration chemicals, those chemicals were representative calibrants ($c$ = 0.92 for the proposed windows and 0.64 for jackknife+), and applying these factors to the NORMAN suspects lowered coverage further (0.842 and 0.733). Selection-aware calibration therefore corrects a known selection rule, not a shift in the kind of compounds being screened; the latter requires calibrants that resemble the analytes.

## Error analysis

With the proposed 90 % windows ($n=20$, first draw), 8.4 % of test compounds fell outside their window, and 55 % of these misses eluted later than the window. Miss rates were highest for phenols (13.1 %), quinolines (12.3 %), organonitrogen compounds (12.2 %) and pyridines (11.1 %) and lowest for indoles (6.4 %), fatty acyls (6.8 %) and steroids (6.9 %) (Table S12). The classes with elevated miss rates contain basic nitrogen or acidic phenolic groups whose ionisation, and hence retention, depends on mobile-phase pH and column chemistry — the selectivity changes that a monotone transfer of a system-independent score cannot represent [@malm2025projection; @kretschmer2026order].

## Computational cost

On a single CPU thread, training the retention-order base model on 82,924 retention times took 4.0 min and training the difficulty model 5.3 s; both are done once, on public data. Calibrating a new system — the leave-one-out maps and difficulty scales of the calibrants — took 28, 56 and 122 ms for 10, 20 and 40 calibrants, and computing the window of a candidate structure 349 µs at $n=20$, so that windows for 10,000 candidates are obtained in a few seconds (peak memory 2660 MB, dominated by the feature table of all RepoRT compounds). The conformal layer thus adds no practical cost to an NTS workflow; its only real cost is the requirement of enough, representative calibrants.

## Practical recommendations

(i) Do not use fixed, proportional or parametric RT tolerances when a model is transferred to a new system: their retention of correct structures is unknown and often far below the nominal value. (ii) Measure at least $1/\alpha-1$ calibrants — 19 for a 95 % window — and preferably 30–40, spread over the elution range and chosen to resemble the analytes. (iii) Use calibrant-based jackknife+ windows; the meta-learned normalisation is worthwhile for long reversed-phase gradients, whereas plain jackknife+ suffices for short gradients and HILIC. (iv) If the calibrants follow a fixed rule (e.g. a standard mix of common compounds), calibrate the windows by replaying that rule on public data, and treat structurally novel candidates and analyte classes absent from the calibrants with caution. (v) Combine the RT window with MS/MS and CCS evidence rather than using it as the sole filter.

## Limitations

The finite-sample guarantee is marginal and rests on exchangeability of calibrants and analytes; it does not extend to fixed calibrant mixes that differ from the analytes, as the NORMAN results show, and it does not imply coverage within compound classes (structurally novel compounds remained under-covered). The selection-aware correction gives an average-over-systems, not a per-system, guarantee and requires that the selection rule and the analyte population can be replayed on public data. The efficiency gain of the learned normalisation was context-dependent (long reversed-phase gradients) and absent in short gradients, HILIC and the external systems. RepoRT is dominated by metabolite standards and by a few large sources whose systems share compounds and laboratories; we used leave-source-out validation, but systems within a source are not independent, and a cluster bootstrap over five sources is necessarily coarse. Isomeric decoys were RepoRT compounds rather than candidate lists from structure databases, and no prospective, wet-laboratory NTS study was performed. Finally, the base model does not encode chromatographic conditions; stronger, condition-aware base models [@kretschmer2026order] would narrow the windows, and the conformal layer applies to them unchanged.


# Conclusions

Retention-time windows derived from parametric error models, fixed tolerances or residual rules do not keep their nominal retention rate when an RT model is transferred to a new chromatographic system with a few calibrants: with 20 calibrants, Gaussian-process intervals discarded the correct structure 1.8 times as often as intended and fixed ±1 min windows kept only 71 % of the correct structures. Calibrant-based jackknife+ windows restored the promised rate on 228 reversed-phase systems, on HILIC systems and on 37 external interlaboratory methods, without any training data from the target system, provided that at least $1/\alpha-1$ calibrants are measured. A difficulty model meta-learned across systems made the windows narrower and more reliable for compounds outside the calibrant range in long reversed-phase gradients, but it was not a universal improvement. The decisive practical condition is that the calibrants resemble the analytes: calibrant mixes of common or unrelated compounds broke the guarantee, a known selection rule could be corrected by replaying it on public data, and a difference between the calibrant and analyte populations could not. Conformal windows do not remove more false candidates than conventional windows at the same retention; their value is that the retention rate becomes a design choice rather than an unknown — which is what a filter that may silently discard the right answer requires. Future work should calibrate RT windows jointly with MS/MS and collision-cross-section evidence and develop calibrant designs and conditional guarantees for structurally novel compounds.
