# Pre-registered experimental plan (written before any target-system result was inspected)

Date: 2026-11-15. Git commit recorded at time of first full run in `results/experiment_logs/run_manifest.json`.

## Problem
In LC–HRMS non-target screening (NTS), predicted retention times (RT) are used to discard candidate structures whose
predicted RT is incompatible with the observed RT of a feature. Laboratories rarely have training data for their own
chromatographic system; they typically measure a small calibrant mix (≈10–50 compounds) and transfer a model or a
public RT library to their system (projection / calibration). The tolerance window used for filtering is set heuristically
(fixed minutes, ±k·RMSE). Neither its coverage (probability of keeping the correct structure) nor its dependence on the
number of calibrants has been characterised across many systems.

## Hypotheses
* H1 (validity of current practice): Gaussian/parametric RT windows derived from a few calibrants (±z·RMSE, smoothing-spline
  and Gaussian-process prediction intervals) under-cover the true RT of non-calibrant compounds on new systems, i.e. discard
  the correct structure more often than the nominal α, with large between-system heterogeneity.
* H2 (validity of the proposed approach): jackknife+ conformal windows computed from the same calibrants keep empirical
  coverage ≥ 1−α (on average over systems and in most individual systems) when calibrants are exchangeable with test compounds.
* H3 (efficiency/adaptivity): normalising the jackknife+ nonconformity scores with a difficulty model meta-learned on OTHER
  chromatographic systems narrows the average window at equal nominal coverage and improves coverage of hard compound
  strata (novel/low-similarity compounds, ionisable compounds, extrapolated retention region).
* H4 (practical value): at matched nominal level, the proposed windows retain the correct candidate at the nominal rate while
  eliminating a substantial fraction of isomeric false candidates.
* H5 (robustness): conclusions hold for (a) both base retention models, (b) calibrant counts 10–40, (c) non-random calibrant
  selection (retention-spanning; commonly-measured compounds), (d) noisy calibrant RTs, (e) strict novel-compound subsets.

## Research questions → experiments
* RQ1 (H1, H2) → E1 main validity/efficiency comparison, primary setting n = 20 calibrants, α = 0.10.
* RQ2 (H3) → E3 ablation of the difficulty model (feature groups; normalisation on/off; LOO refit on/off; mapping family).
* RQ3 (H4) → E6 candidate-filtering experiment with isomeric decoys (same molecular formula, different connectivity).
* RQ4 (H5) → E4 robustness (calibrant number, selection strategy, RT noise, novel compounds), E5 generalisation
  (leave-source-out folds; second base model; HILIC systems as an out-of-mechanism test), E7 sensitivity (α, hyper-parameters
  of the difficulty model), E8 error analysis, E9 computational cost.

## Data and splits
* RepoRT v1.0 (Zenodo 10.5281/zenodo.16267768; sha256 4eeeb46a…6091; CC BY-SA 4.0).
* Target systems: reversed-phase (RP) systems with ≥60 retained compounds after cleaning, excluding SMRT (always a
  training library). Secondary: HILIC systems with ≥60 compounds (E5).
* Outer folds = leave-SOURCE-out (RepoRT `source` field): {BGC}, {Folberth}, {PredRet}, {Souihi, Stoffel}, {all other sources}.
  All models (base retention model, difficulty model) for a target fold are trained only on systems from other sources
  (+ SMRT). No information from the target system other than its calibrants is used.
* Difficulty model training data are generated by simulating the calibrant protocol on training-fold systems with base-model
  predictions obtained by inner cross-fitting (base model refit without the inner held-out systems), so that training
  residuals reflect transfer to unseen systems.
* Within a target system: R = 20 calibrant draws (seeds 0..19, fixed) per calibrant count n ∈ {10, 15, 20, 30, 40};
  test set = all remaining compounds of that system.

## Methods compared (all use the same base score and the same calibrants)
Mapping score→RT on calibrants: monotone (isotonic regression + PCHIP interpolation, linear extrapolation).
* B1 Gaussian ±z_{1−α/2}·RMSE_LOO (current practice)
* B2 P-spline (penalised B-spline, GAM-like) mapping with parametric prediction interval (PredRet-like)
* B3 Gaussian-process mapping with predictive interval (GP projection, cf. García et al. 2022)
* B4 split conformal (half calibrants fit, half calibrate), unnormalised
* B5 jackknife+ (unnormalised)
* B6 jackknife+ normalised by base-model ensemble spread + nearest-neighbour similarity (heuristic UQ features)
* P  jackknife+ normalised by the meta-learned difficulty model (PROPOSED)
* (E3 ablations: P without novelty features / without ionisation features / without system features / without
  calibrant-geometry features; naive jackknife without LOO refit; linear mapping.)

## Metrics
Per system (averaged over draws): empirical coverage, coverage gap (1−α − coverage), mean and median window width
(minutes and % of the system's RT span), Winkler interval score, coverage in strata (novel vs seen compound; ionisable vs
neutral; inside vs outside calibrant score range; ClassyFire superclass), decoy elimination rate (E6).
System-level summary: mean/median over systems, share of systems with coverage < 1−α−0.05 ("severe under-coverage").

## Statistics
Unit of analysis = target system (systems are the independent replicates; draws are averaged within system).
Paired two-sided Wilcoxon signed-rank tests of P vs each comparator on per-system interval score, width and |coverage gap|;
Holm correction within each family; effect size = matched-pairs rank-biserial correlation; 95 % bootstrap CIs (10,000
resamples of systems, cluster bootstrap by source for sensitivity). Coverage validity: one-sided test of mean coverage ≥ 1−α
with system-cluster bootstrap CI. No result-driven seed selection; all seeds fixed in config.

## Fixed hyper-parameters (no tuning on target systems)
* Base model A (multi-system retention-order model): XGBoost rank:pairwise, groups = systems; 600 trees, eta 0.05,
  max_depth 8, subsample 0.8, colsample_bytree 0.5, min_child_weight 5; features = 217 RDKit descriptors + 1024-bit
  Morgan counts (r=2). SMRT subsampled to 15,000 compounds (seed 0) to limit its weight.
* Base model B (SMRT regressor; E5): LightGBM regression on SMRT RT, 1,500 trees, lr 0.03, 127 leaves, feature_fraction 0.5.
* Ensemble spread for B6: 5 bootstrap replicates of base model A with 200 trees each.
* Difficulty model: LightGBM regression of log(|residual|+0.01 min), 400 trees, lr 0.05, 31 leaves, min_data_in_leaf 100.
* α ∈ {0.05, 0.10, 0.20}; primary α = 0.10; primary n = 20.

## Addendum A (2026-11-15, before the full run; after a quick-mode smoke test on tiny models)
* The smoke test (40-tree base models, 2 systems per fold, 2 draws) was used ONLY to verify that the pipeline runs.
  It revealed a correctness bug in baseline B6 (ensemble spread of calibrants computed from maps that had been fitted
  on those same calibrants → spread ≈ 0 → absurdly wide windows). Fixed by computing the spread with leave-one-out
  replicate maps (σ_{-i}), i.e. the same LOO-consistency used for the proposed method. No other change.
* Decoy experiment (E6): decoys = all RepoRT compounds with the same molecular formula and a different InChIKey
  connectivity block, at most 30 per parent compound (seeded sample); evaluated at n = 20 for draws 0–4.
* Strata analysed at n = 20: seen/unseen by base model; max-Tanimoto bins (<0.4, 0.4–0.7, ≥0.7); ionisable vs
  neutral; inside vs outside calibrant score range; RT tertile; top-8 ClassyFire superclasses.
* B2 (P-spline), B3 (GP) and B6 (ensemble) are evaluated at n ∈ {10, 20, 40} only (computational cost).

## Addendum B (2026-11-15 22:35 UTC; written while the main run was in progress and BEFORE any main result was inspected)
Motivated by the ACA journal benchmark (`journal_selection/aca_journal_quality_benchmark.md`), which found that RT papers in
the journal never benchmark against the tolerance windows used in screening practice:
* Added fixed-tolerance baselines evaluated on the identical calibrant draws (same seeds/models): ±0.25, ±0.5, ±1, ±2 min;
  ±5 %, ±10 % of predicted RT; ±2·RMSE_LOO, ±3·RMSE_LOO (`experiments/run_extra_baselines.py`).
* Added an exploratory small-calibrant analysis (n ∈ {5, 8}) to illustrate the n ≥ 1/α − 1 requirement.
These analyses are labelled post hoc/exploratory in the manuscript.

## Addendum C (2026-11-16 03:20 UTC; external validation, specified before any NORMAN result was computed)

laboratories; 41 calibration chemicals and 41 spiked suspects; RT data CSV sha256 of the ESI zip f96093af…4c15).
* Base model: retention-order model trained on ALL RepoRT RP systems (+ SMRT subsample); difficulty model trained on
  simulated transfers of all RepoRT RP systems scored by the leave-source-out outer models. No NORMAN data are used for training.
* Scenarios per system: (E5c-1) calibrants = all NORMAN calibration chemicals detected on that system (fixed mix, n = 12–36),
  test = suspects; (E5c-2) n ∈ {10, 20} random calibrants from the calibration-chemical pool, test = suspects (20 draws);
  (E5c-3) n ∈ {10, 20} random calibrants from all compounds (exchangeable), test = all other compounds (20 draws).
* Methods B1–B5 and P; α ∈ {0.05, 0.10, 0.20}; metrics as in the main study; unit = system (37).
* System descriptors from ESI Table S1 (pH class and modifier from mobile-phase text, USP class from stationary phase,
  column length and particle size from dimensions, gradient length from the ESI code table); unavailable descriptors
  (temperature, flow, dead time) are left missing (handled natively by LightGBM).
