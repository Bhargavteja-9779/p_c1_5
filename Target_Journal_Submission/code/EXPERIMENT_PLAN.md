# Pre-registered experimental plan (written before any target-system result was inspected)

Date: 2026-11-15. Git commit recorded at time of first full run in `results/experiment_logs/run_manifest.json`.

## Problem
In LC–HRMS non-target screening (NTS), predicted retention times (RT) are used to discard candidate structures whose
predicted RT is incompatible with the observed RT of a feature. Laboratories rarely have training data for their own
chromatographic system; they typically measure a small calibrant mix (≈10–50 compounds) and transfer a model or a
public RT library to their system (projection / calibration). The tolerance window used for filtering is set heuristically
(fixed minutes, ±k·RMSE). Neither its coverage (probability of keeping the correct structure) nor its dependence on the
number of calibrants has been characterised across many systems.

## Hypotheses
* H1 (validity of current practice): Gaussian/parametric RT windows derived from a few calibrants (±z·RMSE, smoothing-spline
  and Gaussian-process prediction intervals) under-cover the true RT of non-calibrant compounds on new systems, i.e. discard
  the correct structure more often than the nominal α, with large between-system heterogeneity.
* H2 (validity of the proposed approach): jackknife+ conformal windows computed from the same calibrants keep empirical
  coverage ≥ 1−α (on average over systems and in most individual systems) when calibrants are exchangeable with test compounds.
* H3 (efficiency/adaptivity): normalising the jackknife+ nonconformity scores with a difficulty model meta-learned on OTHER
  chromatographic systems narrows the average window at equal nominal coverage and improves coverage of hard compound
  strata (novel/low-similarity compounds, ionisable compounds, extrapolated retention region).
* H4 (practical value): at matched nominal level, the proposed windows retain the correct candidate at the nominal rate while
  eliminating a substantial fraction of isomeric false candidates.
* H5 (robustness): conclusions hold for (a) both base retention models, (b) calibrant counts 10–40, (c) non-random calibrant
  selection (retention-spanning; commonly-measured compounds), (d) noisy calibrant RTs, (e) strict novel-compound subsets.

## Research questions → experiments
* RQ1 (H1, H2) → E1 main validity/efficiency comparison, primary setting n = 20 calibrants, α = 0.10.
* RQ2 (H3) → E3 ablation of the difficulty model (feature groups; normalisation on/off; LOO refit on/off; mapping family).
* RQ3 (H4) → E6 candidate-filtering experiment with isomeric decoys (same molecular formula, different connectivity).
* RQ4 (H5) → E4 robustness (calibrant number, selection strategy, RT noise, novel compounds), E5 generalisation
  (leave-source-out folds; second base model; HILIC systems as an out-of-mechanism test), E7 sensitivity (α, hyper-parameters
  of the difficulty model), E8 error analysis, E9 computational cost.

## Data and splits
* RepoRT v1.0 (Zenodo 10.5281/zenodo.16267768; sha256 4eeeb46a…6091; CC BY-SA 4.0).
* Target systems: reversed-phase (RP) systems with ≥60 retained compounds after cleaning, excluding SMRT (always a
  training library). Secondary: HILIC systems with ≥60 compounds (E5).
* Outer folds = leave-SOURCE-out (RepoRT `source` field): {BGC}, {Folberth}, {PredRet}, {Souihi, Stoffel}, {all other sources}.
  All models (base retention model, difficulty model) for a target fold are trained only on systems from other sources
  (+ SMRT). No information from the target system other than its calibrants is used.
* Difficulty model training data are generated by simulating the calibrant protocol on training-fold systems with base-model
  predictions obtained by inner cross-fitting (base model refit without the inner held-out systems), so that training
  residuals reflect transfer to unseen systems.
* Within a target system: R = 20 calibrant draws (seeds 0..19, fixed) per calibrant count n ∈ {10, 15, 20, 30, 40};
  test set = all remaining compounds of that system.

## Methods compared (all use the same base score and the same calibrants)
Mapping score→RT on calibrants: monotone (isotonic regression + PCHIP interpolation, linear extrapolation).
* B1 Gaussian ±z_{1−α/2}·RMSE_LOO (current practice)
* B2 P-spline (penalised B-spline, GAM-like) mapping with parametric prediction interval (PredRet-like)
* B3 Gaussian-process mapping with predictive interval (GP projection, cf. García et al. 2022)
* B4 split conformal (half calibrants fit, half calibrate), unnormalised
* B5 jackknife+ (unnormalised)
* B6 jackknife+ normalised by base-model ensemble spread + nearest-neighbour similarity (heuristic UQ features)
* P  jackknife+ normalised by the meta-learned difficulty model (PROPOSED)
* (E3 ablations: P without novelty features / without ionisation features / without system features / without
  calibrant-geometry features; naive jackknife without LOO refit; linear mapping.)

## Metrics
Per system (averaged over draws): empirical coverage, coverage gap (1−α − coverage), mean and median window width
(minutes and % of the system's RT span), Winkler interval score, coverage in strata (novel vs seen compound; ionisable vs
neutral; inside vs outside calibrant score range; ClassyFire superclass), decoy elimination rate (E6).
System-level summary: mean/median over systems, share of systems with coverage < 1−α−0.05 ("severe under-coverage").

## Statistics
Unit of analysis = target system (systems are the independent replicates; draws are averaged within system).
Paired two-sided Wilcoxon signed-rank tests of P vs each comparator on per-system interval score, width and |coverage gap|;
Holm correction within each family; effect size = matched-pairs rank-biserial correlation; 95 % bootstrap CIs (10,000
resamples of systems, cluster bootstrap by source for sensitivity). Coverage validity: one-sided test of mean coverage ≥ 1−α
with system-cluster bootstrap CI. No result-driven seed selection; all seeds fixed in config.

## Fixed hyper-parameters (no tuning on target systems)
* Base model A (multi-system retention-order model): XGBoost rank:pairwise, groups = systems; 600 trees, eta 0.05,
  max_depth 8, subsample 0.8, colsample_bytree 0.5, min_child_weight 5; features = 217 RDKit descriptors + 1024-bit
  Morgan counts (r=2). SMRT subsampled to 15,000 compounds (seed 0) to limit its weight.
* Base model B (SMRT regressor; E5): LightGBM regression on SMRT RT, 1,500 trees, lr 0.03, 127 leaves, feature_fraction 0.5.
* Ensemble spread for B6: 5 bootstrap replicates of base model A with 200 trees each.
* Difficulty model: LightGBM regression of log(|residual|+0.01 min), 400 trees, lr 0.05, 31 leaves, min_data_in_leaf 100.
* α ∈ {0.05, 0.10, 0.20}; primary α = 0.10; primary n = 20.

## Addendum A (2026-11-15, before the full run; after a quick-mode smoke test on tiny models)
* The smoke test (40-tree base models, 2 systems per fold, 2 draws) was used ONLY to verify that the pipeline runs.
  It revealed a correctness bug in baseline B6 (ensemble spread of calibrants computed from maps that had been fitted
  on those same calibrants → spread ≈ 0 → absurdly wide windows). Fixed by computing the spread with leave-one-out
  replicate maps (σ_{-i}), i.e. the same LOO-consistency used for the proposed method. No other change.
* Decoy experiment (E6): decoys = all RepoRT compounds with the same molecular formula and a different InChIKey
  connectivity block, at most 30 per parent compound (seeded sample); evaluated at n = 20 for draws 0–4.
* Strata analysed at n = 20: seen/unseen by base model; max-Tanimoto bins (<0.4, 0.4–0.7, ≥0.7); ionisable vs
  neutral; inside vs outside calibrant score range; RT tertile; top-8 ClassyFire superclasses.
* B2 (P-spline), B3 (GP) and B6 (ensemble) are evaluated at n ∈ {10, 20, 40} only (computational cost).

## Addendum D (2026-11-16 04:12 UTC) — Phase-19 improvement: selection-aware system-level calibration (SASC)
Specified after observing (robustness run, commonly-measured calibrants) that all methods under-cover when calibrants
are not random draws (mean coverage 0.815 proposed, 0.746 jackknife+), and BEFORE any SASC result was computed.
* Problem: the finite-sample guarantee requires calibrants exchangeable with the analytes; laboratories use fixed or
  rule-based calibrant mixes (well-known, early-clustering compounds), which are easier to predict and leave much of the
  RT range to extrapolation.
* Hypothesis H7: if the calibrant-selection rule is known, replaying it on other chromatographic systems (treated as
  exchangeable units) identifies a single inflation factor c for the normalised scores such that average coverage over
  systems reaches 1 − α; applying c on the target system restores near-nominal coverage under that rule at a moderate
  cost in width, without target-system data beyond the calibrants.
* Method: for outer fold f and rule ρ ∈ {random, span, common, NORMAN-mix}, for every training system s (folds ≠ f;
  ≥ 40 compounds) and 5 draws: compute normalised jackknife+ windows with inner models (base model M_{f,g} and difficulty
  model σ_{f,g} trained without s's source group g) and the coverage curve cov_s(c) on a grid c ∈ [0.5, 6] (step 0.02),
  where c multiplies every σ_{-i}(x)R_i term; choose c_ρ = min{c : mean_s cov_s(c) ≥ 1 − α}. For plain jackknife+ the same
  with σ ≡ 1. NORMAN-mix rule on RepoRT systems: calibrants = NORMAN calibration chemicals present in the system (≥10).
* Evaluation: n = 20, α = 0.10, rules random/span/common on all 228 target systems (10 draws; same seeds as the robustness
  runs) and the NORMAN fixed mix (37 external systems); metrics as before; comparison: P vs P+SASC vs J+ vs J+SASC.
* Reporting: post hoc (Phase-19) improvement; the original pre-registered results remain the primary results.

## Addendum E (2026-11-16, written and committed BEFORE running; post hoc, prompted by the citation audit)
Motivation: comparator B3 fits the GP hyper-parameters on the target calibrants only, whereas the GP projection of
García et al. (2022) meta-learns its prior on other chromatographic methods. A meta-learned prior may give better-calibrated
predictive intervals with few calibrants, so B3 alone could understate the strongest parametric alternative.
* New comparator B7 "GP projection with meta-learned hyper-parameters": GP on calibrant-standardised base score and RT,
  kernel = constant + linear + RBF, Gaussian noise; the five hyper-parameters are meta-learned per leave-source-out fold on the
  training systems only (inner cross-fitting as for the difficulty model; simulated calibrant draws n = 10, 20, 40, 3 draws,
  seeds as for the difficulty-model simulation; objective = mean Gaussian predictive log-likelihood of held-out compounds,
  systems weighted equally; L-BFGS-B, two starts). The fixed hyper-parameters are applied to the target systems of the fold.
  Interval: posterior predictive mean ± z_{1−α/2} × predictive sd.
* Evaluation: identical calibrant draws to the main study (same seeds; verified by recomputing jackknife+ coverage for n = 20,
  draw 0), all n ∈ {10, 15, 20, 30, 40} and α ∈ {0.05, 0.10, 0.20}; same metrics and per-system statistics as the main
  comparators (Table 2, paired Wilcoxon tests with Holm correction, one-sided coverage test). B7 is reported in all main
  tables as an additional comparator, whatever its result. Code: experiments/run_metagp.py.
* Amendment (2026-11-16, before any target-system result of B7 was computed or inspected): in the first run the meta-learned
  constant, linear and RBF variances of every fold sat at the upper optimisation bound (exp(3) in calibrant-standardised units),
  i.e. the bound, not the data, determined the solution. The bounds were widened to exp(9) for the variances and exp(3) for the
  noise variance, and the run was restarted; the first run was stopped before its evaluation stage.
* **Correction (2026-11-16 19:10 UTC, after review cycle 1, reviewer R3).** The amendment above states that "the first run was
  stopped before its evaluation stage". This is incorrect. The first run completed its target evaluation in the short interval
  between printing the hyper-parameter table and being stopped, and its outputs (metagp_rows.parquet, metagp_check.csv,
  metagp_theta.csv) were committed together with the amendment in commit 38de8b5. When the bounds were widened, only the
  hyper-parameter table had been looked at, not the coverage results. Both runs are now reported: run 1 (bounds exp(3)) is kept
  as results/raw/metagp_rows_run1_bounds_exp3.parquet (+ metagp_theta_run1_bounds_exp3.csv); run 2 (bounds exp(9)) is the
  analysed version. At n = 20, α = 0.10: run 1 coverage 0.974, median width 11.2 min, interval score 13.2 min; run 2 0.973,
  12.0 min, 14.2 min — the conclusion does not depend on the bounds, and the widening made B7 slightly less, not more, efficient.

## Addendum F (2026-11-16 19:15 UTC, after review cycle 1; written and committed BEFORE running)
1. **Fold-specific compound frequencies for the 'common' calibrant rule (correction).** The rule ranked compounds by the number
   of RepoRT systems in which they were measured, counted over all systems including the held-out source group. Counts are now
   taken only from systems of the same separation mode outside the held-out group (for target systems of fold f: folds ≠ f; for
   the replay on a training system of fold g within outer fold f: folds ∉ {f, g}). The 'commonly measured calibrants'
   robustness experiment and the SASC experiment are re-run with these counts and replace the earlier results; the earlier
   results are kept for comparison (results/raw/*_allfreq_*).
2. **Out-of-sample validation of SASC on a new selection rule ('polar').** Calibrants = the n = 20 compounds of a system with the
   lowest computed logP (Crippen MolLogP; random tie-break), mimicking a mix of polar standards. The rule was chosen without
   looking at any result for it. Evaluation exactly as for the other SASC rules (factor c per fold from replaying the rule on
   training systems; 10 draws per target system — identical sets apart from tie-breaks; P, P+SASC, J+, J+SASC; mean coverage,
   share of systems < 0.85, median width, interval score, per-source coverage). SASC is considered validated on this rule if
   the mean coverage of P+SASC and J+SASC over the target systems is within 0.88–0.92 (nominal 0.90); otherwise it is reported
   as not validated.

## Addendum G (2026-11-21, pre-run): cross-system conformal calibration with laboratory-level guarantees (XSC)
Motivation (review cycle 1, A01/A04/A06; desk rejections for insufficient novelty): jackknife+ windows control only the
*average* retention over laboratories (per-draw coverage < 0.85 in 17 % of draws at n = 20), need n ≥ 1/α − 1 calibrants,
and the meta-learned σ adds little within jackknife+. XSC uses the laboratory's calibrants only for the monotone map and a
scale τ̂ (RMS of LOO residuals, optionally σ-normalised and shrunk towards the meta-learned prediction with k = 5 pseudo-
calibrants), and calibrates the window multiplier c over training systems on which the laboratory's protocol (n, selection
rule) is replayed (systems = exchangeable units; base and σ models never saw the calibrating system).
Targets: (avg) mean retention ≥ 1 − α; (lab) P{laboratory's own retention ≥ 1 − ε} ≥ 1 − δ, δ = 0.10 fixed a priori.
Families: flat (σ ≡ 1; = calibrated ±k·RMSE of A01), sig, sigs (shrunk); JP_lab = jackknife+ with a lab-level multiplier.
n ∈ {3, 5, 10, 20, 40}; rules random/span/common/polar; 8 replay draws per training system; target draws = main experiment.
Primary endpoints (n = 20, random, α = ε = 0.10): lab-level failure rate P(coverage < 0.90) (target ≤ 0.10) and median
width for XSC_sigs_lab vs JP_lab, B5 and B1; secondary: n = 3/5 (finite windows below 1/α − 1), non-random rules, NORMAN.
Script: experiments/novelty/run_xsc.py; outputs results/raw/xsc/.
